# 0.5.14 日程删除验证

2026-10-07 在当前 Windows x64 主机完成；未分别验收 Windows 10 和 Windows 11。

- 日程页新增多选模式，支持单击切换选择、全选、清空选择和按选中数量确认批量删除。普通模式中的完成、稍后提醒和单项删除仍可用。
- ISAC 的 Chat Completions 和 Responses 工具清单均包含 `delete_event`；工具按稳定 ID 查找，未知 ID 不会删除数据。提示词要求先查询日程，多个候选项时先确认。
- `test_schedule_delete.py` 覆盖工具删除、未知 ID、多选刷新保持、取消确认、批量删除、全选/清空和较大字号下的按钮布局。
- 29 个 `test_*.py` 回归脚本全部通过；正式 EXE 的 `--smoke` 退出码为 0。
- 从 `release/SHDDesktop.exe` 启动后，正式控制台可见，日程页显示“多选”入口；桌面右键及开机启动注册路径均指向正式 EXE。

真实大模型是否按预期选择删除工具仍取决于接入的模型服务，本次没有发送实际模型请求。旧版退出时曾短暂出现内容未留存的 Warning 窗口；当时没有新增崩溃日志或图标恢复日志，原因未能确认。

此 Codex 命令环境继承了旧 PyInstaller 进程的 `_PYI_*` 解包变量。直接在同一命令环境启动同路径 EXE 会误用失效的 `_MEI` 临时目录并报 DLL 加载错误；仅在启动命令的子环境清除这些残留变量后，正式路径运行正常。普通 Explorer 启动不继承这些变量。
